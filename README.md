### Hi, I'm John Draper

I've had a few careers — soldier, and these days a part-time dentist. Somewhere in
between I picked up an MS in Data Science from Eastern University, and now I build
things with it, mostly for the satisfaction of making something work.

That splits into two streams. I build **AI pipelines that make media family-friendly**:
[revox](https://github.com/john-draper/revox) (real-time video profanity censoring),
[audiobook-censor-pipeline](https://github.com/john-draper/audiobook-censor-pipeline)
(detect-and-replace profanity in audiobooks with voice-cloned TTS), and
[MangaProfanityFilter](https://github.com/john-draper/MangaProfanityFilter) (OCR and
text replacement for manga pages). And I **measure whether analysis tools actually
work**: a paired recall/discrimination benchmark for stack buffer overflow (CWE-121)
static analyzers and LLM code reviewers, extending Paul E. Black's NIST
effectiveness-test-suite work — because a tool that warns about everything detects
nothing.
